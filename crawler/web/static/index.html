    Snapshot & Methoden

    Die lokale Preview nutzt den explizit gebundenen Snapshot. Nicht verfügbare Verfahren werden nicht ersetzt. Ergebnisse und Quellenreferenzen können als kanonisches JSON oder Markdown exportiert werden.

    Privatsphäre & Weitergabe

    Suchanfragen werden nur im jeweiligen Research-Prozess verarbeitet: lokal auf dem Rechner oder bei einem freigegebenen Pilot auf dem geschützten Projektserver. Es werden keine externen Modelle aufgerufen. Eine kurze Ergebnishistorie liegt nur im Arbeitsspeicher; ein Neustart verwirft sie.

    Die Research Preview ist nicht öffentlich freigegeben. Die Weitergabe vollständiger Quellen und Auszüge erfordert eine Rechteentscheidung. Ein Link zum offiziellen Original ist davon getrennt zu prüfen.

    Eine öffentliche Bereitstellung benötigt freigegebene Daten, Zugriffskontrolle und eine separate Sicherheitsabnahme.
